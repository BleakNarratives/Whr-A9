# EquiLex VS Code Extension Prototype

This is a starter scaffold for a VS Code extension that exposes EquiLex commands to Android developers.

## Commands
- `EquiLex: Generate Privacy Policy`
- `EquiLex: Validate TOS Structure`
- `EquiLex: Open Copilot Integration Guide`

## Getting started
1. Install dependencies:
   ```bash
   cd tools/equilex-vscode-extension
   npm install
   ```
2. Build the extension:
   ```bash
   npm run compile
   ```
3. Open the folder in VS Code and launch the Extension Development Host.
