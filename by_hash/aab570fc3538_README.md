# AI DAW Engine

## Overview
This engine serves as the core synthesis pipeline for the "Riffusion-Meta-Graph" beat-maker, integrating graph-informed musical theory with real-time persistent hive state management.

## Integration
- **Hive State (`Whorl`):** Manages real-time musical context.
- **Synthesis:** `HuggingFaceSynthesisProvider` utilizing free-tier inference.
- **Listener Agent:** Monitors audio for adaptive vocal collaboration.
