### Evolution Algorithm
```python
# Genetic algorithm implementation
def next_generation(self, fitness_metrics):
    # 1. Evaluate fitness for all processes
    self.evaluate_fitness(fitness_metrics)
    
    # 2. Record statistics
    self.record_fitness_history()
    
    # 3. Select parents using tournament selection
    parents = self.tournament_selection()
    
    # 4. Create offspring through breeding and mutation
    offspring = self.create_offspring(parents)
    
    # 5. Apply elitism - keep top performers
    elites = self.select_elites()
    
    # 6. Form new population
    self.population = elites + offspring
    
    # 7. Increment generation
    self.generation += 1
```
