# CODE CITY
Built on a phone. Zero budget. Maximum output.

## Setup
1. Add API key: `nano shared/config/config.yaml`
2. Test: `python3 test_suite.py`
3. Use: `python3 -m obelisk.boardroom.vertical_ai`

## Modules
- Boardroom: Board of directors AI analysis
- Rapper: Beat generation (MIDI)
- Firefly: Real-time analytics (coming soon)
- Askhole: Brutal code review (coming soon)
