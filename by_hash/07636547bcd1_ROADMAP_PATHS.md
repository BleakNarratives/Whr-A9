# CodeCity-Bench: Development Roadmaps

## Track 1: Backend/Server Integration (Medium)
- Implement a lightweight Python web server (using `http.server` or `FastAPI`).
- Expose the TelemetryBridge via REST API.
- Live-stream topological updates to the web frontend.

## Track 2: Apocalypse Visualization (Quickest)
- Integrate advanced HTML/JS visualizations (e.g., `code_city_apocalypse.html`).
- Add a switcher in the workbench to toggle between "Topology" and "Apocalypse" modes.
- Cleanup assets and optimize paths.

## Track 3: Workbench UI Phase (Complex)
- Develop a unified CLI/Web dashboard.
- Create a configuration wizard for scanner selection.
- Implement real-time monitoring of scan progress and data aggregation.
