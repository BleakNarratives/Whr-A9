⚡ Quick Start (30 Seconds)

1

Start Your Session

2

Chat with Qwen

3

📋 Command Reference

Core Commands

Command Description When to Use
qchat Interactive Qwen chat Pair programming, debugging, design
qquery "X" Single query Quick facts, explanations
qmcp MCP server management Managing AI tools & extensions
qwen_start Load session context Starting work
qwen_end Save session state Ending work

Navigation Commands

Command Description

qcontext Show project context

Direct Qwen CLI

qwen "prompt"              # Single query
qwen -i                    # Interactive mode
qwen -m model "prompt"     # Specific model
qwen mcp                   # MCP management

🔧 Troubleshooting

⚠️ "modmind_architect not available"

Fix: Ignore it. Qwen commands still work. This is a known fallback behavior.

⚠️ "qwen command not found"

# Check if installed
which qwen

# Install if missing
npm install -g @mmmbuto/qwen-code-termux

⚠️ "Permission denied"

# Make scripts executable
chmod +x ~/bin/qwen_*.sh
chmod +x ~/Code_City_Unified/tools/qwen_cli/*.py

⚠️ Session context lost

# Check session log
cat ~/.qwen/session_log.md | tail -100

# Your work is logged there
