# Code City Unified: The Super-Repo

## 🏙️ Overview
Code City Unified is an autonomous AI agent framework designed for terminal-based strategic orchestration, network reconnaissance, and codebase visualization. It merges the evolutionary "Vertical AI" boardroom logic with the "Code City Apocalypse" visual diagnostics engine.

## 🚀 Key Features

### 1. ModMind Architect
The central nervous system. Uses heuristic intent recognition to route tasks to specialized sub-modules.
- **Commands**: `battle`, `scan`, `boardroom`, `apocalypse`.

### 2. Vertical Swarm (Boardroom)
A strategic decision-making layer where three AI personas (Chairman, Adversary, Architect) debate project direction and generate **Strategic Directives**.
- **Location**: `vertical_swarm/`
- **Memory**: Powered by `Mnemonic Core` (persistent state).

### 3. Red Team Hunt
Multi-threaded network reconnaissance and port scanning tool.
- **Location**: `modmind_unified/src/red_team.py`

### 4. Code City Apocalypse
A diagnostic visualizer that transforms your codebase into a "City" where file size determines building height and bugs manifest as environmental disasters.
- **Location**: `code_city/apocalypse.py`

### 5. Celtic Data Loom
A high-complexity cryptographic data-linking system using "Fibers" and "Knots" for secure information weaving.
- **Location**: `vertical_swarm/celtic/`

## 🛠️ Usage

### Running the CLI
```bash
python3 Code_City_Unified/code_city/modmind_cli.py
```

### Examples
- `"Start a boardroom meeting about security"` -> Triggers Vertical Swarm.
- `"Run scan on 192.168.1.1"` -> Triggers Red Team.
- `"Apocalypse"` -> Generates codebase visual map.
- `"Titan Battle"` -> Starts the terminal RPG.

## 📁 Repository Structure
- `code_city/`: CLI entry point and Apocalypse engine.
- `modmind_unified/`: Original Architect logic and Red Team modules.
- `vertical_swarm/`: Boardroom logic, Celtic crypto, and security tools.
- `data/`: Persistent state, checkpoints, and logs.
- `docs/`: Architecture diagrams and logs.
- `tests/`: Unit tests for core stability.
