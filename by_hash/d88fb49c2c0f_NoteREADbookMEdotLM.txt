⚙️ How It Works: The Workflow
CodeMentor operates as a "value bridge" between raw AI output and developer upskilling
.
Select Code: Highlight any multi-line code block in your editor

Trigger Command: Use the Command Palette (Ctrl+Shift+P) to run one of the three modes

Review Output: A dedicated CodeMentor Webview Panel opens, displaying structured teaching logic

Autonomous Protocol (Optional): Toggle Auto-Workflow to automatically chain Explain → Compare → Quiz in a single sequence
