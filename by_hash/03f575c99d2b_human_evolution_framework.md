## 🎬 Example: Motivation Evolution

```python
# Create base motivation DNA
motivation_dna = HumanDNA(
    name="Base Motivation",
    traits={
        "drive": 0.5,
        "discipline": 0.3,
        "consistency": 0.4
    }
)

# Add motivation strategies
strategy1 = StrategyDNA(
    name="Morning Routine",
    parameters={"duration": 30, "activities": ["meditation", "exercise"]}
)

strategy2 = StrategyDNA(
    name="Goal Setting",
    parameters={"frequency": "daily", "method": "SMART"}
)

motivation_dna.add_strategy(strategy1)
motivation_dna.add_strategy(strategy2)

# Evolve motivation
for generation in range(10):
    # Mutate strategies
    mutated = motivation_dna.mutate()
    
    # Evaluate fitness
    metrics = {
        "productivity": 0.7 + (generation * 0.02),
        "consistency": 0.6 + (generation * 0.01),
        "wellbeing": 0.8 - (generation * 0.005)
    }
    
    fitness = mutated.calculate_fitness(metrics)
    
    # Select best performer
    if fitness > motivation_dna.fitness_score:
        motivation_dna = mutated
        print(f"Generation {generation}: Improved fitness to {fitness:.3f}")

# Result: Optimized motivation system
print(f"Final Motivation DNA - Fitness: {motivation_dna.fitness_score:.3f}")
```
